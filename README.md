# カコモと学ぶ 決算チャレンジ 教育費編

加古川市 令和7年度一般会計決算「教育費」(約94.2億円、29事業)を、
クイズと予算判断シミュレーションで学べる単一HTMLファイルのPWAです。

## 構成

- `index.html` — 本体(データ埋め込み済み、そのまま公開可能)
- `manifest.json` — PWA用マニフェスト
- `sw.js` — Service Worker(オフラインキャッシュ)
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` — アイコン(カコモ、款名なしのため他款と共通利用可)
- `og-image.png` — SNSシェア用画像(教育費・約94.2億円と明記、款が変わるたびに作り直し)

## コンテンツ

1. **入口クイズ層**(全44問、2択)
   - 基礎知識(5問): kessansho_r7.xlsxの「項」別内訳(教育総務費・小学校費・中学校費・特別支援学校費・特別支援教育費・幼稚園費・社会教育費・保健体育費)
   - 予算vs決算当てっこ(29問): 全事業対象
   - 特別トリビア(10問): 前年度比急増急減の理由問い6問+AI視点の「気になる点」(ベンダー集中等)4問
2. **本編シミュレーション層**: 教育費29事業全部を対象。法定給付(7件)/裁量事業(22件)のカテゴリから選び、増額/維持/減額/廃止を判断
3. **答え合わせ層**: 議事録公開待ちのため未実装(民生費・総務費と同様)

## 法定給付/裁量事業の分類

法定(7件): 小学校就学奨励事業、中学校就学奨励事業、特別支援教育就学奨励事業、
教育施設等利用給付事業、放課後児童健全育成事業、学校保健事業、文化財調査事業

裁量(22件): 上記以外の全事業

## データソース

- `seika_houkokusho_r7.xlsx`(一般会計_事業一覧、PDFページ182〜210)
- `kessansho_r7.xlsx`(歳出・款項別内訳)
- `kessan_meisai_r7.xlsx`(支払先明細)
- `202608240902.pdf`(令和7年度各会計歳入歳出決算報告書・事業報告書)

## 公開時の注意

- `og-image.png`は款名・金額入りのため、次款作成時は作り直しが必要です。
- アイコン一式(icon-192/512, apple-touch-icon)は款名の文言が入っていないため、
  今後の款(教育費の次は公債費を検討中)でもそのまま使い回せます。
